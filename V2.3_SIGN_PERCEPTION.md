## 1. Overview & Objectives

In facility environments such as warehouses and research hospitals, visual signage provides human-readable landmark guidance. The **V2.3 Sign Perception System** allows the autonomous robot to visually recognize facility signage, interpret directional guidance (e.g. `STORAGE ->`, `<- HOSPITAL`), associate detected signs with semantic destinations in `semantic_destinations.yaml`, and stream the annotated sign perception feed live to the dashboard.

## 3. Visual Sign Recognition Pipeline

The sign recognition pipeline processes the `/camera/image_raw` feed (15 Hz) using OpenCV:

```
Camera Frame (640x480)
          ↓
Color Pre-filtering & Contrast Normalization (CLAHE)
          ↓
Morphological Text/Sign Region Proposals
          ↓
Multi-Scale Template Matching & OCR Character Feature Extraction
          ↓
Directional Arrow Detection (Left Arrow '←', Right Arrow '→', Straight)
          ↓
Semantic Association via `semantic_destinations.yaml`
          ↓
Publish `/vision/annotated_signs` & Store in SQLite `signs` Table
```

### Sign Detection Data Schema (`/vision/sign_detections`):
- `sign_id`: Unique identifier (e.g. `sign_storage_01`)
- `text`: Recognized string (e.g. `"STORAGE ->"`)
- `semantic_destination`: Mapped destination (`"storage"`)
- `direction`: Directional arrow interpretation (`"RIGHT"`, `"LEFT"`, or `"FORWARD"`)
- `confidence`: Match score (typically 0.82 to 0.96)
- `bounding_box`: Pixel bounds `[ymin, xmin, ymax, xmax]`

The web dashboard on port 5050 was upgraded to incorporate a second live perception view in the Screen 1 Bottom Drawer:

```
+-------------------------------------------------------------------------+
| LIVE PERCEPTION FEED                          [ YOLO View ] [ Sign View ] [ Raw ] |

|  [ Camera Frame Display with Active Bounding Boxes & Tracking Badges ]  |

```

### View Modes:
1. **`YOLO View` (`/api/camera_frame?view=yolo`):** Shows detected facility objects (carts, persons, forklifts, hospital beds) with 2D bounding boxes and class names.
2. **`Sign View` (`/api/camera_frame?view=signs`):** Highlights detected directional signs with vibrant green bounding boxes, destination badges, and directional arrows.
3. **`Raw View` (`/api/camera_frame?view=raw`):** Displays uncompressed, unmodified camera frames directly from the simulated sensor.

The image automatically refreshes at 5 Hz via an optimized REST buffer endpoint, providing real-time visual situational awareness with zero browser lag.

## 5. Landmark-Assisted Destination Confirmation

When navigating towards a semantic destination (e.g. `STORAGE`), the decision engine monitors sign detections:
- If the robot arrives at a junction and the camera detects `STORAGE ->` with confidence $>0.80$, the decision engine confirms that the robot is on the correct branch corridor.
- The visual confirmation event is logged to the SQLite database and highlighted in the dashboard event log:
  ```
  [INFO] Visual Landmark Confirmed: Sign "STORAGE ->" sighted with 91.4% confidence.
  ```
