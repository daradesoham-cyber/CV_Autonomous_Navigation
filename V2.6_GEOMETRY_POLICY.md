## 2. Navigation Clearance Standards

To ensure repeatable, collision-free autonomous navigation without controller oscillations or inflation jamming, all facility features are classified into three strict operational regimes:

| Feature Category | Minimum Physical Width ($W_{\text{min}}$) | Required Clearance Buffer ($\Delta_{\text{clear}}$) | Classification Thresholds |
| :--- | :--- | :--- | :--- |
| **A. Straight Corridor** | $0.90\text{ m}$ | $\ge 0.23\text{ m}$ each side | $W \ge 1.20\text{ m}$: `NAVIGABLE`<br>$0.85\text{ m} \le W < 1.20\text{ m}$: `RESTRICTED`<br>$W < 0.85\text{ m}$: `NON-NAVIGABLE` |
| **B. Doorway Passage** | $0.85\text{ m}$ | $\ge 0.20\text{ m}$ each side | $W \ge 1.20\text{ m}$: `NAVIGABLE`<br>$0.80\text{ m} \le W < 1.20\text{ m}$: `RESTRICTED`<br>$W < 0.80\text{ m}$: `NON-NAVIGABLE` |
| **C. 90-Degree Turn** | $1.10\text{ m} \times 1.10\text{ m}$ | $\ge 0.25\text{ m}$ corner buffer | Clearance $\ge 1.10\text{ m}$: `NAVIGABLE`<br>$Clearance < 1.10\text{ m}$: `NON-NAVIGABLE` |
| **D. Multi-Way Junction** | $1.40\text{ m} \times 1.40\text{ m}$ | $\ge 0.35\text{ m}$ turning room | Diameter $\ge 1.40\text{ m}$: `NAVIGABLE` |

## 3. Costmap Inflation Interactions

With Nav2 costmap parameters frozen at:
- `inflation_radius = 0.30 m`
- `cost_scaling_factor = 4.5`
- `robot_radius = 0.22 m`

1. **Inscribed Cost Zone:** Extends to $0.22\text{ m}$ from any obstacle boundary.
2. **Decay Inflation Zone:** Extends from $0.22\text{ m}$ to $0.30\text{ m}$.
3. **Bottleneck Critical Condition:**
   - Any gap where distance between obstacles $W_{\text{gap}} < 2 \times 0.22\text{ m} = 0.44\text{ m}$ is physically impassable.
   - Any gap where $W_{\text{gap}} < 2 \times 0.30\text{ m} = 0.60\text{ m}$ contains overlapping inflation costs that prevent NavfnPlanner from finding a legal path.
   - Therefore, **the absolute minimum passable opening in Nav2 without clear-costmap recovery is $0.65\text{ m}$, and the certified operational minimum is $0.85\text{ m}$**.

## 4. Topological Node Placement Invariants

1. **Centerline Invariant:** Every waypoint must be positioned within $\pm 0.15\text{ m}$ of the local corridor or doorway centerline.
2. **Obstacle Clearance Invariant:** The minimum distance from any node $(x_n, y_n)$ to the nearest static obstacle boundary must be $\ge 0.45\text{ m}$ ($\text{robot\_radius} + \text{inflation\_radius}$).
3. **Turn Approach Invariant:** Waypoints preceding a 90° turn must be located at least $0.80\text{ m}$ before the corner to allow the pure pursuit controller to establish lookahead convergence.
